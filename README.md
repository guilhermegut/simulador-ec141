# Simulador de Escalas – Emenda Constitucional 141 (Fim da 6x1)

Simulador de escalas e custos para a adequação à Emenda Constitucional 141/2026 (Fim da 6x1), do Claudio Zalaf Advogados Associados.

O cálculo roda inteiro no navegador de quem usa: nenhum dado digitado é enviado a servidor. A página funciona também sem internet depois da primeira visita.

Publicação: GitHub Pages, a partir da pasta raiz da branch `main`.
